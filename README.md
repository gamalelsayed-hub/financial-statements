# القوائم المالية من ميزان المراجعة

برنامج كمبيوتر (ويندوز) يحوّل ميزان المراجعة إلى قوائم مالية كاملة وتحليل مالي، بالعربي والإنجليزي.

## خطوات الاستخدام

1. **رفع ميزان المراجعة** (Excel أو CSV): كود الحساب، اسم الحساب، ثم ٦ أعمدة:
   أول المدة (مدين/دائن) — الحركة (مدين/دائن) — آخر المدة (مدين/دائن).
   البرنامج يتعرف على الأعمدة تلقائيًا ويعرض شاشة لتعديلها، ويراجع توازن الميزان.
   - لو عمود الحركة أو آخر المدة مش موجود، البرنامج يحسبه.
   - الحسابات الرئيسية (اللي كودها بداية لحسابات فرعية) بتتستبعد تلقائيًا عشان ما تتكررش.
2. **تصنيف الحسابات**: البرنامج يقترح تصنيف لكل حساب من اسمه. تراجع وتعدّل
   (ضغطة مزدوجة على خانة التصنيف، أو تحدد كذا صف وتطبق تصنيف واحد).
   البرنامج يفتكر تصنيفاتك للمرة الجاية، وتقدر تحفظ التصنيف في ملف.
3. **تأكيد وإنشاء القوائم المالية**:
   - قائمة المركز المالي (مقارنة آخر المدة بأول المدة)
   - قائمة الدخل
   - قائمة التدفقات النقدية بالطريقة غير المباشرة (مبنية تلقائيًا من التصنيف)
   - قائمة التغير في حقوق الملكية
   - الإيضاحات (الحسابات المكوّنة لكل بند)
   - مراجعة التوازن (المركز المالي، صافي الربح، النقدية)
4. **التحليل المالي**: ٢٧ مؤشر في السيولة والربحية والنشاط التشغيلي والتمويل والتدفقات النقدية، مع تقييم وملخص مكتوب.
5. **التصدير**: Excel (كل قائمة في شيت + التصنيف) و PDF.

## إزاي كل تصنيف بيروح لقائمة التدفقات

| التصنيف | في التدفقات النقدية |
|---|---|
| العملاء، المخزون، المصروفات المقدمة، الموردين، المستحقات، الضرائب | تشغيلية (التغير في رأس المال العامل) |
| مجمع الإهلاك، المخصصات | تشغيلية (تسوية بنود غير نقدية) |
| الأصول الثابتة، مشروعات تحت التنفيذ، الأصول غير الملموسة، الاستثمارات | استثمارية |
| القروض والبنوك الدائنة، رأس المال، التوزيعات، الأرباح المرحلة والاحتياطيات | تمويلية |
| النقدية وما في حكمها | ناتج القائمة (يُطابق مع الرصيد الفعلي) |

## التشغيل وبناء ملف exe

- **تشغيل مباشر** (محتاج Python 3.10 أو أحدث): `run.bat`
- **بناء برنامج exe على ويندوز**: شغّل `build_windows.bat` وهتلاقي البرنامج في
  `dist\FinancialStatements\FinancialStatements.exe` (انسخ فولدر `FinancialStatements` كله لأي جهاز).
- **بناء تلقائي على GitHub**: ارفع المشروع على GitHub، وملف `.github/workflows/build-windows.yml`
  يبني البرنامج تلقائيًا وتنزّله من صفحة Actions → Artifacts.

## هيكل المشروع

```
main.py                    نقطة التشغيل
fsapp/categories.py        التصنيفات وربطها بالقوائم والتدفقات
fsapp/importer.py          قراءة ميزان المراجعة والتحقق منه
fsapp/classifier.py        اقتراح التصنيف وحفظه
fsapp/engine.py            بناء القوائم والمؤشرات
fsapp/reports.py           عرض القوائم (للشاشة و PDF)
fsapp/export_excel.py      التصدير إلى Excel
fsapp/i18n.py              النصوص بالعربي والإنجليزي
fsapp/ui/main_window.py    واجهة البرنامج
sample/                    ميزان مراجعة نموذجي للتجربة
tests/                     اختبارات
```
