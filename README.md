# نظام التقارير المالية والإدارية

برنامج كمبيوتر (ويندوز) يقدر أي محاسب يستخدمه: يعمل إعدادات الشركة، ويربط دليل الحسابات بالقوائم،
ويرفع ميزان كل شهر وحركة الفروع، فيطلع له القوائم المالية الكاملة والتحليل الشهري وتحليل الفروع.

## أول مرة

عند التشغيل تظهر شاشة البداية:
- **شركة جديدة**: ينشئ ملف شركة (`.fsdb`) فيه البنود الافتراضية، وبعدها ترفع الموازين وتربط الحسابات.
- **فتح ملف شركة**: كل شركة ملف واحد تقدر تنقله أو تحفظ منه نسخة احتياطية.
- **استيراد شركة من ملف Excel (النموذج القديم)**: ينقل الإعدادات والفروع والعملات والبنود والربط والحركة الشهرية
  وميزان الفترة الحالية وميزان المقارنة وحركة الفروع من ملف النموذج مرة واحدة.
- **تحليل سريع لميزان واحد**: الأداة البسيطة (ميزان واحد ← قوائم مالية).

## الشاشات

| الشاشة | ما تفعله |
|---|---|
| 📊 لوحة التحكم | بطاقات الشهر (الربحية، النقد والتمويل، رأس المال العامل بالأيام)، الخلاصة والتنبيهات (من موّل مَن، أكبر بند حبس الكاش، تحول الربح لكاش، أشهر التدفق السالب، المصروفات فوق المتوسط، العملاء المطلوب مطابقتهم، الموردون المتجاوزون)، 6 رسوم بيانية، وتحليل رأس المال العامل مع القراءة. تصدير PDF و Excel |
| ⚙ الإعدادات | اسم الشركة، أول شهر في السنة المالية، نسبة المبيعات الآجلة، حدود تنبيه المصروفات، الفروع ومناطقها، العملات، **قاعدة أرقام الحسابات** (1 أصول، 2 التزامات، 3 حقوق ملكية، 4 إيرادات، 5 مصروفات — قابلة للتعديل) |
| 📋 البنود | بنود القوائم (والقسم ودورها في النسب)، بنود التدفق (والنشاط)، فئات دخل الفروع، مجموعات المصروفات |
| 🔗 ربط الحسابات | لكل حساب: بند القائمة، بند التدفق، فئة دخل الفروع، مجموعة المصروف، ثابت/متغير. فلاتر للحسابات الناقصة أو التي لا يتفق ربطها مع رقمها، تعيين جماعي، **اقتراح ربط تلقائي**، استيراد/تصدير Excel |
| 🗓 البيانات الشهرية | رفع ميزان شهر (الأعمدة الستة)، حركة الفروع (ملف لكل فرع أو ملف واحد بعمود للفرع)، أعمار العملاء، أعمار الموردين. يعرض توازن كل شهر |
| 📈 التقارير | 11 تقرير للفترة + 10 تقارير شهرية، مع اختيار الفترة وطولها (شهر/ربع/نصف/سنة) والمقارنة، والتصدير Excel و PDF |

## التقارير

**تقارير الفترة**: الملخص التنفيذي، المطابقات والفحوصات، **تشخيص الخلل**، المركز المالي، قائمة الدخل (الفترة،
المقارنة، من بداية السنة، المتوسط الشهري)، التدفقات النقدية (غير المباشرة)، مصادر النقد واستخداماته، دخل الفروع
وتوزيع مصروفات الإدارة، تحليل مصروفات فرع، تحليل المصروفات بين فترتين، النسب المالية، تحليل أرصدة العملاء
(حسب الفرع والمندوب وأعلى المتأخرين — المتأخر: العهدة > 30 يوم وغيرها > 60 يوم)، تحليل أرصدة الموردين (حسب العملة
والمتجاوز لفترة الائتمان بسعر الصرف).

**التحليل الشهري**: قائمة الدخل الشهرية بالأرباع، المصروفات حسب المجموعة، المركز المالي نهاية كل شهر، المؤشرات
الشهرية، التدفقات الشهرية، «الكاش راح فين؟»، مصادر واستخدامات النقد شهريًا، الفروع شهريًا (المبيعات والربح بعد
التوزيع)، تحليل فرع شهريًا.

## تشخيص الخلل

لو القوائم لم تتوازن أو في ربط غير منطقي، تقرير «تشخيص الخلل» يحدد الحسابات المسببة بالضبط ومبلغ كل منها
(مجموع المبالغ = الفرق) والحل المقترح:
- الميزان نفسه غير متوازن: حساب يساوي الفرق (ناقص/مكرر)، حساب يساوي نصف الفرق (في الجانب الخطأ)، فرق يقبل
  القسمة على 9 (تبديل أرقام)، حسابات رئيسية مع فرعياتها.
- فرق المركز المالي: الحسابات غير المربوطة مع اقتراح البند حسب رقمها واسمها.
- فرق التدفقات: حسابات ميزانية بلا بند تدفق، حسابات نقدية غير متسقة.
- حسابات ربطها لا يتفق مع رقمها (مثلًا رقم يبدأ بـ 4 مربوط بالميزانية) — يغير الربح حتى لو القوائم متوازنة.
- أرصدة على غير طبيعتها (أصل دائن / التزام مدين)، وأرصدة أول الشهر ≠ آخر الشهر السابق.

## التشغيل وبناء البرنامج

- تشغيل مباشر (Python 3.10+): `run.bat`
- بناء exe على ويندوز: `build_windows.bat` ← `dist\FinancialStatements\FinancialStatements.exe`
- بناء تلقائي: كل رفع على GitHub يبني البرنامج ويرفعه في صفحة Actions → Artifacts.
