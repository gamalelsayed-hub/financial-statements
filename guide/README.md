# دليل بناء البرنامج

يولّد صفحة HTML فيها كل ملفات البرنامج مقسمة على مراحل، ولكل دالة شرح عربي وكودها الفعلي.

- `stages.py`: المراحل وترتيب الملفات.
- `desc/<الملف>.py`: شرح كل ملف (FILE) وكل جزء فيه (DESC).
- `basics.html`: قسم «ابدأ من هنا».
- `practice.html`: تمرين «من وصف إلى كود».
- `template.html`: شكل الصفحة.

التشغيل من داخل هذا المجلد:

    python check.py   # يتأكد أن كل دالة في الكود لها شرح
    python gen.py     # يكتب guide.html

بعد أي تعديل في كود البرنامج: شغّل check.py، واكتب شرحًا لأي دالة جديدة أو متغيرة في desc، ثم gen.py وانشر الصفحة على نفس رابط الدليل.
