2 كيف يفكر المبرمج: كأنك تكلم موظف ينفذ حرفيًا

الكمبيوتر موظف سريع جدًا، ما يتعب ولا يغلط في الحساب، بس عنده عيب واحد: ما يخمّن أبدًا. ينفذ اللي قلته بالحرف، لا أكثر ولا أقل. البرمجة يعني تكلمه بالتفاصيل وبالترتيب: روح، افتح، لكل صف، لو كذا سوّ كذا، اجمع، هات النتيجة.

لو قلت لمحاسب عندك «طلّع لي مبيعات أكتوبر لكل عميل»، بيفهم لحاله إنه يتجاهل الصفوف الفاضية، ويعتبر المبلغ الفاضي صفر، ويرتب من الأكبر، ويفهم التاريخ لو مكتوب بشكل غريب. الكمبيوتر ما يعرف أي شي من هذا إلا إذا قلته له. عشان كذا نص أي كود تقريبًا شروط من نوع «لو فاضي… لو نص… لو برا الفترة…».

الخطوة 1: افهم إيش تحتاج

قبل أي سطر كود، جاوب على ثلاث أسئلة: وش المدخلات (ملف؟ أي أعمدة؟ أي شيت؟)، وش المخرجات (رقم؟ جدول؟ ملف إكسيل؟ مرتب كيف؟)، ووش القاعدة اللي تحول هذا لذاك (جمع؟ فلتر؟ مقارنة؟). لو ما تقدر تشرحها لإنسان بوضوح، ما تقدر تكتبها لكمبيوتر.

الخطوة 2: خمّن كل الاحتمالات اللي تخلي النتيجة غلط

هذي أهم خطوة، وهي اللي تفرق كود يشتغل مرة عن كود تعتمد عليه. اسأل نفسك: «وش ممكن يكون غلط في البيانات؟» وكل جواب يصير شرط if في الكود. وهنا ميزتك كمحاسب: أنت تعرف أصلًا وين البيانات تخرب.

ومع ذلك: لازم تتعلم أساسيات اللغة نفسها

التفكير بالخطوات هو نص الشغل، والنص الثاني إنك تعرف تتكلم لغة الكمبيوتر. زي اللي يعرف وش يبي يقول بس لازم يعرف كلمات وقواعد اللغة عشان يقوله. في بايثون هذا يعني:

  • المفردات: أنواع البيانات (رقم، نص، تاريخ، None)، والقائمة [ ]، والقاموس { }، والمتغيرات.
  • التراكيب: if و for و def و return و import، وكيف تتداخل مع بعض.
  • القواعد: الإزاحة (4 مسافات) هي اللي تحدد وش داخل وش، والنقطتين : قبل أي كتلة، والترقيم يبدأ من صفر، والحروف الكبيرة والصغيرة تفرق.
  • المكتبات: ما تحفظها، تعرف إنها موجودة وتدور على طريقة استخدامها وقت الحاجة (openpyxl للإكسيل، sqlite3 لقاعدة البيانات، datetime للتواريخ).

والأخبار الحلوة: الأساسيات محدودة، وتشوفها كلها في البطاقات العشر تحت (القسم 6) ومن كود البرنامج نفسه. ما تحتاج تحفظ: تفهم الفكرة، وتعرف وش تدوّر عليه، والتكرار يثبتها لحاله.

تمرّن عليها: في قسم «تمرين: من وصف إلى كود» تحت، اكتب وصفك ماشي على الخطوات الأربع، وشوف كم درجتك. لو نقصت، غالبًا نسيت احتمال من الخطوة 2.

3 الأدوات: بايثون و VS Code

بايثون هو اللي يشغّل الكود. وVS Code برنامج كتابة (زي الوورد بس للكود): يلوّن الكود، ويكتشف الأخطاء وأنت تكتب، وفيه شاشة أوامر تحت. الاثنين مجانيين.

أولًا: تأكد إن بايثون موجود

  1. اضغط زر ويندوز، واكتب cmd، واضغط Enter. تنفتح شاشة سوداء اسمها «موجه الأوامر».
  2. اكتب python --version واضغط Enter.
  3. لو طلع رقم 3.10 أو أحدث فأنت جاهز. لو طلعت رسالة إنه مو موجود، نزّله من python.org، ووقت التثبيت علّم على Add python.exe to PATH (مهم جدًا، بدونه موجه الأوامر ما يعرف بايثون).

ثانيًا: ثبّت VS Code وجهّز مجلد المشروع

  1. نزّل VS Code من code.visualstudio.com وثبّته.
  2. افتحه، واضغط أيقونة الإضافات (رقم 4 في الرسمة تحت)، وابحث عن Python وثبّت الإضافة اللي ناشرها Microsoft.
  3. سوّ مجلد فاضي على جهازك، مثلًا C:\fsapp-project.
  4. في VS Code: File → Open Folder واختر المجلد. يطلع اسمه في شريط الملفات (رقم 1).
  5. لإنشاء مجلد أو ملف: وقف بالماوس على شريط الملفات، وبتطلع أيقونتين صغار: «ملف جديد» و«مجلد جديد». أو كليك يمين ← New File / New Folder.
  6. اكتب الكود في منطقة الكتابة (رقم 2)، واحفظ بـ Ctrl + S. النقطة البيضاء جنب اسم الملف تعني إنه مو محفوظ.
  7. افتح شاشة الأوامر من القائمة: Terminal → New Terminal (رقم 3). هنا تكتب أوامر التثبيت والتشغيل والتجارب، وهي مفتوحة على مجلد المشروع مباشرة.
  8. أول أمر تكتبه هناك يثبت المكتبات الأربع اللي يحتاجها البرنامج:
pip install PySide6==6.12.0 openpyxl==3.1.5 pdfplumber==0.11.10 certifi==2024.8.30

5 ليش ملف __init__.py؟

تشبيه: تخيل البرنامج عمارة، وكل مجلد غرفة. بايثون ما يدخل أي غرفة إلا لو على بابها لوحة مكتوب فيها «هذي الغرفة جزء من البرنامج». ملف __init__.py هو هاللوحة. وجوده بس يكفي، فيبقى فاضي تمامًا بدون أي كود.

المجلد اللي فيه هالملف يسمونه في بايثون «حزمة» (package). فعشان كذا عندنا ثلاث نسخ منه، وحدة في كل مجلد: fsapp و fsapp/system و fsapp/ui.

وين يفرق؟ في سطور الاستيراد (import) اللي تجيب كود من ملف ثاني. شوف كيف بايثون يقرأ هالسطر كأنه عنوان:

from fsapp.system.db import CompanyDB
fsappمجلد، ولازم فيه __init__.py
systemمجلد داخله، ولازم فيه __init__.py
dbالملف db.py (نكتبه بدون .py)
CompanyDBالكلاس المكتوب داخل الملف

يعني: «روح لمجلد fsapp، ثم مجلد system، ثم ملف db.py، وجيب منه CompanyDB». لو نسيت __init__.py في أي مجلد من الطريق، يطلع لك الخطأ ModuleNotFoundError.

والنقطة في بداية الاستيراد؟ بتشوف داخل الملفات سطور مثل from . import defaults و from ..system import calc:

  • نقطة وحدة . = «من نفس المجلد اللي أنا فيه».
  • نقطتين .. = «من المجلد اللي فوقي». مثلًا ملف داخل ui يكتب ..system عشان يطلع لـ fsapp ثم يدخل system.

6 أساسيات بايثون من كود البرنامج نفسه

هذي أكثر الأشياء اللي بتتكرر في كل الملفات. كل مثال مأخوذ من البرنامج، وتحته ترجمته بالكلام العادي.

التعليق (ملاحظة لك، بايثون يتجاهلها)

# 0 means a development copy
"""Report builders. Every report is a list of tables."""
  • أي سطر يبدأ بـ # ملاحظة.
  • النص بين ثلاث علامات تنصيص """ في أول ملف أو دالة اسمه docstring: وصف للملف أو الدالة.

المتغير: اسم تحفظ فيه قيمة

BUILD = 0
REPO = "gamalelsayed-hub/financial-statements"
  • = تعني «احفظ». فالسطر الأول: احفظ الرقم صفر باسم BUILD.
  • النص لازم بين علامتي تنصيص، والرقم بدونها.
  • الاسم كله حروف كبيرة = اتفاق بين المبرمجين إنه ثابت ما يتغير.

القائمة (list): مجموعة قيم بالترتيب

BS_SECTIONS = ["CA", "NCA", "CL", "NCL", "EQ"]
BS_SECTIONS[0]      # → "CA"   (العد يبدأ من صفر)
  • بين قوسين مربعين [ ] والعناصر بينها فاصلة.
  • تجيب عنصر برقمه، وأول عنصر رقمه 0.

القاموس (dict): كل مفتاح وقيمته

SECTION_NAMES = {"CA": "الأصول المتداولة", "CL": "الخصوم المتداولة"}
SECTION_NAMES["CA"]   # → "الأصول المتداولة"
  • بين قوسين معقوفين { }، وكل زوج «مفتاح: قيمة».
  • زي جدول من عمودين: تعطيه المفتاح ويرجع القيمة. البرنامج يستخدمه كثير، مثلًا {رقم الحساب: بياناته}.

الدالة (def): مجموعة أوامر لها اسم

def month_label(p):
    return f"{MONTHS_AR[int(p[5:7]) - 1]} {p[:4]}"

month_label("2026-09")   # → "سبتمبر 2026"
  1. def = «عرّف دالة»، واسمها month_label، وتاخذ قيمة وحدة اسمها p (الشهر).
  2. p[5:7] يقص الحروف من 5 إلى 7: من "2026-09" يطلع "09"، و int يحوله لرقم 9.
  3. ناقص واحد لأن قائمة الشهور تبدأ من صفر، فيجيب «سبتمبر»، ويضيف السنة p[:4].
  4. return = «رجّع هالنتيجة لمن ناداني».
  5. f"..." نص تقدر تحط داخله قيم بين { }.

الشرط (if): نفذ فقط لو...

def safe_div(a, b):
    if a is None or b is None or abs(b) < 1e-9:
        return None
    return a / b
  • بالعربي: «لو أ فاضي، أو ب فاضي، أو ب صفر تقريبًا، رجّع لا شي. وإلا رجّع أ ÷ ب».
  • None = «لا شي / فاضي». و 1e-9 رقم صغير جدًا (0.000000001).
  • فايدتها: القسمة على صفر في بايثون تطلع خطأ وتوقف البرنامج، فهالدالة تحمي النسب منه.

التكرار (for): كرر لكل عنصر

total = 0
for a in accounts:
    total = total + a.close_net
  • بالعربي: «ابدأ المجموع بصفر، وامشِ على الحسابات واحد واحد (كل واحد اسمه a)، وأضف ختامه للمجموع».
  • بتشوف كثير الشكل المختصر: sum(a.close_net for a in accounts) ويعني نفس الشي في سطر واحد.

  • كل نقطة · هنا تمثل مسافة. السطور اللي تحت def أو if أو for لازم تتأخر 4 مسافات عشان بايثون يعرف إنها «داخلها».

7 كيف تجرب كودك وتقرأ الأخطاء

آخر كل مرحلة فيه «جرّب قبل ما تكمل». التجربة تكون في شاشة الأوامر داخل VS Code: تكتب python وتضغط Enter، فتتحول الشاشة لوضع بايثون (يطلع >>>). كل سطر تكتبه يتنفذ فورًا ويطلع جوابه. وللخروج تكتب exit().

شكل رسالة الخطأ: لو فيه غلط يطلع نص طويل اسمه Traceback. اقرأ آخر سطر أول: فيه نوع الخطأ وسببه. والسطر اللي فوقه فيه اسم الملف ورقم السطر اللي فيه الغلط.
