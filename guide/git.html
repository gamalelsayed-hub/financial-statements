استراحة بعد المرحلة 1: احفظ شغلك بـ Git

خلصت أول ثلاث ملفات وشغالة؟ هذا أحسن وقت تتعلم تحفظ «لقطة» من شغلك، عشان لو خربت شي بعدين ترجع له. القسم هذا مو إجباري، بس بيوفر عليك وقت كثير.

1 وش هو Git، ووش الفرق بينه وبين GitHub؟

Gitبرنامج على جهازك يسجل تاريخ كل تعديل في الكود. مثل دفتر اليومية: كل قيد بتاريخه وشرحه.
GitHubموقع تحفظ فيه نسخة من هالتاريخ برا جهازك. مثل الأرشيف في المقر الرئيسي.

تبدأ بـ Git بس على جهازك. GitHub تضيفه بعدين لما تتعود (آخر القسم).

الكلمة الأهم: commit (التزام) = لقطة محفوظة من كل ملفات المشروع في لحظة معينة، ومعها جملة تشرح وش تغير. فكر فيها كقيد يومية.

2 التثبيت والإعداد (مرة وحدة بس)

  1. نزّل Git من git-scm.com ← Download for Windows، وثبّته وخلّ كل الخيارات زي ما هي (Next لين النهاية).
  2. اقفل VS Code وافتحه من جديد عشان يشوف Git.
  3. في شاشة الأوامر (Ctrl + `) اكتب اسمك وإيميلك، عشان كل لقطة يتسجل مين سواها:
git config --global user.name "اسمك"
git config --global user.email "ايميلك@example.com"

تأكد إنه تثبت: git --version لازم يطلع رقم مثل git version 2.47.0.

3 أول لقطة: من الأزرار بدون أوامر

  1. اضغط أيقونة Source Control 1.
  2. أول مرة بس: يطلع زر Initialize Repository، اضغطه. كذا فتحت «دفتر يومية» للمشروع (يسوي مجلد مخفي اسمه .git، لا تلمسه).
  3. تطلع ملفاتك تحت Changes 2.
  4. في المربع 3 اكتب جملة تشرح وش سويت، مثل: «المرحلة 1: version و defaults و db».
  5. اضغط Commit 4. لو سألك «ما فيه ملفات مجهزة، تبي أجهز الكل؟» اضغط Yes أو Always.

خلاص، هذي أول لقطة. القائمة تفضى لأن ما فيه تغيير من آخر لقطة.

5 خربت شي؟ ثلاث طرق ترجع فيها

الموقفوش تسوي
تبي تشوف وش غيرت من آخر لقطةفي Source Control اضغط على اسم الملف. ينفتح على الجانبين: يسار القديم، يمين الجديد. الأحمر انحذف والأخضر انضاف.
ملف واحد خربته وتبي ترجعه زي آخر لقطةوقّف بالماوس على اسم الملف في Changes واضغط السهم المنحني (Discard Changes). انتبه: تعديلاتك عليه من آخر لقطة تروح.
تبي تشوف كل اللقطات القديمةتحت في Source Control قسم Graph أو Timeline: كل لقطة بتاريخها وشرحها، وتضغط عليها تشوف وش تغير فيها.

6 نفس الشي بالأوامر (للمعرفة)

الأزرار تسوي هالأوامر من ورا. تعرفها عشان لو شفتها في مكان تفهمها:

git init                      # ابدأ دفتر يومية للمشروع (مرة وحدة)
git status                    # وش الملفات اللي تغيرت؟
git add .                     # جهّز كل التعديلات للقطة
git commit -m "شرح التعديل"    # خذ اللقطة
git log --oneline             # اعرض كل اللقطات
git diff                      # وش تغير من آخر لقطة بالضبط

7 بعدين: نسخة على GitHub

لما تتعود على اللقطات، تقدر ترفعها على GitHub عشان تكون عندك نسخة احتياطية وتشتغل من أكثر من جهاز:

  1. سوّ حساب على github.com (أو استخدم حسابك الحالي).
  2. في Source Control اضغط Publish Branch، واختر Private (خاص، ما يشوفه غيرك).
  3. يطلب منك تسجيل الدخول لـ GitHub من المتصفح مرة وحدة.
  4. بعدها كل ما تاخذ لقطة اضغط Sync Changes عشان ترفعها.

تنبيه مهم: لا ترفع أبدًا ملفات فيها بيانات حقيقية (موازين، تقارير عملاء، ملفات .fsdb). خلّها في مجلد برا المشروع، أو سوّ ملف اسمه .gitignore في المشروع واكتب فيه أسماء الأشياء اللي Git يتجاهلها:

*.fsdb
*.xlsx
*.pdf
__pycache__/
